# Brad Lavender - Professional Resume Website

A modern, responsive HTML resume website showcasing Brad Lavender's professional experience as a Full-Stack Developer.

## Features

- **Responsive Design**: Optimized for desktop, tablet, and mobile devices
- **Modern Styling**: Clean, professional layout with smooth animations
- **Print-Friendly**: Optimized CSS for professional printing
- **Interactive Elements**: Hover effects and smooth scrolling
- **Accessibility**: Semantic HTML structure and keyboard navigation support

## Technologies Used

- **HTML5**: Semantic markup structure
- **CSS3**: Modern styling with gradients, animations, and flexbox/grid layouts
- **JavaScript**: Interactive features and smooth animations
- **Font Awesome**: Professional icons
- **Google Fonts**: Inter font family for clean typography

## File Structure

```
├── index.html          # Main HTML file
├── styles.css          # CSS styling and responsive design
├── script.js           # JavaScript for interactivity
├── README.md           # Project documentation
└── .github/
    └── copilot-instructions.md
```

## How to View

1. **Local Viewing**: Open `index.html` in any modern web browser
2. **Live Server**: Use VS Code Live Server extension for development
3. **Print Version**: Use Ctrl+P (Cmd+P on Mac) or click the Print button

## Key Sections

- **Header**: Name and contact information with professional styling
- **Professional Summary**: Brief overview of skills and experience
- **Technology Summary**: Organized tech stack by categories
- **Career History**: Detailed work experience with achievements

## Browser Compatibility

- Chrome 60+
- Firefox 55+
- Safari 12+
- Edge 79+

## Development

To modify or enhance the resume:

1. Edit content in `index.html`
2. Adjust styling in `styles.css`
3. Add functionality in `script.js`
4. Test responsiveness on different screen sizes

## Print Optimization

The website includes specific print styles for professional resume printing:
- Optimized colors and layout for print
- Proper page breaks
- Print button for easy access
